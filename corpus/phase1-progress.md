# Johar AI Phase 1 — 200 MB Corpus Progress

Target processed corpus: 200 MiB (209,715,200 bytes)

## Current checkpoint

- Source catalog started and machine-readable manifest exists.
- Initial high-value public-domain/open/government sources identified across anthropology, folklore, language, gazetteers, census, tourism, biodiversity and geology.
- Ingestion policy: preserve page/chapter provenance; historical sources stay historical; current facts require current sources; no partisan ranking.
- Current stage: source acquisition + ingestion setup.
